# Check-That-Everyday-Checklists
A lightweight, multi-checklist web application built for everyday use with light and dark mode and zero clutter.

## ✨ Features

* **Multi-Checklist Support:** Seamlessly switch between different lists (e.g., Travel Pack, Groceries, Workouts) or create new ones instantly using the dropdown menu.
* **Subsections & Customization:** Organize items into custom subcategories with built-in inline renaming support.
* **Smart Filtering & Search:** Quickly filter out completed items using the "Missing" toggle or search through items in real-time.
* **Dark Mode Ready:** Smooth light and dark theme toggling with an eye-friendly, glare-free color palette designed for long sessions.
* **100% Offline & Private:** Powered entirely by browser `localStorage`. Your data stays safe on your device, and the application works completely offline.

* **Handy Utilities:** 
  * 🖨️ Clean print view for physical copies.
  * 📋 Copy your active list directly to your clipboard as text.
  * 📤 JSON Export and Import for easy backups and syncing across devices.
  * ↩️ Accidental deletion "Undo" protection.

## How to Use
Simply open this application in any modern web browser (Chrome, Safari, Edge, Firefox). No installation or setup required!
